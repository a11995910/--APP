# 金融贷款提醒应用

一个帮助用户管理贷款还款计划的多端应用，包含移动端（uni-app）、后台管理端（Vue 3）与后端服务（Node.js + Express + MySQL）。

## 项目结构

```text
金融APP/
├── server/      # 后端 API 服务
├── admin/       # 后台管理系统
└── mobile/      # 移动端应用（H5/小程序/APP）
```

## 功能清单

### 移动端

- 用户登录/注册（手机号）
- 首页还款动态展示
- Banner 轮播与外链跳转
- 贷款管理（新增、编辑、删除、标记结清）
- 个人中心与自动通知渠道展示（无需用户手动设置）
- APP 推送设备绑定与启动同步

### 后台管理端

- 管理员登录
- 仪表盘统计
- 用户管理
- 贷款管理
- Banner 管理（含图片上传）
- 通知记录管理
- 短信平台配置管理

### 后端服务

- JWT 鉴权
- MySQL 数据持久化
- 统一响应/错误处理
- 上传服务
- 每日定时还款提醒任务
- APP 推送设备登记与最新活跃设备维护

## 技术栈

- 后端：Node.js、Express、MySQL、JWT
- 后台：Vue 3、Vite、Element Plus、Pinia
- 移动端：uni-app、Vue 3、Pinia

## 本地启动

### 1. 启动后端

```bash
cd server
npm install
mysql -u root -p < database/init.sql
npm run dev
```

默认地址：`http://localhost:3000`

### 2. 启动后台管理端

```bash
cd admin
npm install
npm run dev
```

默认地址：`http://localhost:5173`

### 3. 启动移动端（H5）

```bash
cd mobile
npm install
npm run dev:h5
```

默认地址：`http://localhost:5174`
